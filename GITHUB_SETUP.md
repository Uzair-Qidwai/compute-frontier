# Repository maintenance

The complete Compute Frontier source is maintained at https://github.com/Uzair-Qidwai/compute-frontier on `main`.

Clone the repository and follow README.md to run and validate the dashboard. All required assets, including both map images, are included; no build is required.

For future changes, use a branch and pull request when appropriate. Never commit credentials or local environment files. `.openai/hosting.json` records the existing Sites project binding without secrets.

GitHub pushes do not automatically publish to ChatGPT Sites. Publish through the existing Sites project and verify the deployment separately.
